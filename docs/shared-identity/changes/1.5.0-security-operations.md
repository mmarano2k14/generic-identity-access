# Generic Identity 1.5.0 — Security Operations Change Record

**Date:** 2026-10-01  
**Classification:** Additive public SDK and shared presentation release

## Summary

This release promotes the existing server-backed session-revocation, MFA-administration, authenticator-lifecycle and security-audit capabilities into the categorized Generic Identity SDK and shared React/Next.js presentation surface. Existing compatibility APIs remain intact.

## Added

- `@generic-identity/contracts/security-operations`;
- `@generic-identity/auth/security-operations`;
- `GenericIdentityClient.security`;
- categorized `security.sessions`, `security.mfa` and `security.audit` clients;
- reusable `SecurityAuditPage`;
- reusable `MfaPolicyForm`;
- reusable `AuthenticatorRevocationForm`;
- reusable `SessionRevocationForm`;
- `@generic-identity/react/security-operations`;
- `@generic-identity/next/security-operations`;
- source qualification for the Security Operations boundary.

## Modified

- aligned Generic Identity package versions from `1.4.0` to `1.5.0`;
- `MfaPage` now accepts and renders installed provider metadata;
- the live SDK feature inventory now marks backend-supported Security Operations capabilities complete;
- public package documentation now lists the Security Operations category.

## Moved

None.

## Deleted

None.

## Database migrations

None.

## Runtime changes

None in the Generic Identity backend. The new SDK facade composes existing TypeScript transport clients and existing server endpoints.

## Breaking changes

None. Existing administration and compatibility surfaces remain available.

## Security impact

No authorization shortcut is introduced. Session revocation, MFA administration, authenticator revocation and audit access continue to rely on server-side authorization and the existing backend semantics. Internal-only enrollment services are not exposed through speculative public contracts.

## Post-apply validation

The release must preserve:

- Generic Identity contracts typecheck;
- Generic Identity auth SDK typecheck;
- Security Operations public subpath exports;
- aligned `1.5.0` package versions;
- no consumer-product naming in reusable Security Operations source;
- no fake TOTP/WebAuthn/recovery-code enrollment endpoint;
- no backend endpoint, database schema, MFA/session semantic or RBAC semantic change;
- all previously qualified validation gates.
